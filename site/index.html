Convierte Odoo en tu fábrica de software Turn Odoo into your software factory

Kizuku usa Odoo como backend y le agrega lo que falta para crear aplicaciones: entornos separados, un panel para el equipo, historial de versiones y un agente que construye y despliega. Todo en tu propio host. Kizuku uses Odoo as the backend and adds what is missing to build applications: separate environments, a team panel, version history and an agent that builds and deploys. All on your own host.

01 · Qué es01 · What it is

Tu backend ya existe. Falta lo demás. Your backend already exists. The rest is missing.

Kizuku no es un ERP nuevo ni un wrapper: es la fábrica que convierte Odoo en el backend de tus aplicaciones y se ocupa del ciclo completo, desde la primera idea hasta producción. Kizuku is not a new ERP or a wrapper: it is the factory that turns Odoo into the backend of your applications and handles the whole lifecycle, from the first idea to production.

01

No empiezas de cero You do not start from zero

Usuarios, permisos, contactos, ventas, proyectos, correo y reportes ya vienen con Odoo. No se reescriben: se reutilizan. Users, permissions, contacts, sales, projects, mail and reports already ship with Odoo. They are reused, not rebuilt.

02

Tus apps, separadas de Odoo Your apps, separate from Odoo

La aplicación habla con una API segura y Odoo queda detrás, fuera del alcance del navegador. Solo se expone lo que decides exponer. The app talks to a secure API and Odoo stays behind it, out of the browser's reach. Only what you decide to expose is exposed.

03

Un entorno por etapa One environment per stage

dev, staging y prod viven aislados en el mismo host, cada uno con su base y sus usuarios. Lo que rompes en dev no toca a tus clientes. dev, staging and prod live isolated on the same host, each with its own database and users. What you break in dev never reaches your customers.

04 · Cómo se usa04 · How it works

Tú decides. El agente construye. You decide. The agent builds.

El equipo trabaja en el panel; el agente hace el trabajo técnico desde el editor. Nadie necesita memorizar comandos. The team works in the panel; the agent does the technical work from the editor. Nobody has to memorise commands.

01

Creas el proyectoCreate the project

Desde el panel eliges nombre y plantilla, y obtienes la URL del entorno de desarrollo.From the panel you pick a name and a template and get the development URL.

02

El agente construyeThe agent builds

Le pides lo que quieres y arma el modelo, la API y las pantallas, valida y despliega a dev.You ask for what you want and it builds the model, the API and the screens, validates and deploys to dev.

03

Apruebas producciónYou approve production

Cuando está listo, promueves desde el panel. Producción pide confirmación y guarda el historial.When it is ready you promote from the panel. Production asks for confirmation and keeps the history.
