## Scaffold

```bash
core-odoo project create my-project --template odoo-module
# placeholders are replaced with the project/module name
```

The module is mounted read-only at `/mnt/extra-addons` by the environment
template. Install it on first boot with `ODOO_INIT_MODULES=__MODULE__`.

## Tests

```bash
core-odoo deploy my-project --stage dev --modules __MODULE__
# Odoo runs tests tagged post_install during module installation
```

`TransactionCase` tests run inside a rolled-back transaction, so they never
leave data behind.

## Notes

- Replace `__MODULE__` with the technical module name (snake_case) and
  `__MODULE_TITLE__` with its human-readable title.
- Keep `version` in sync with the Odoo series (`20.0.x.y.z`).
- Add data files to `__manifest__.py["data"]` in dependency order.

## Odoo 20 permissions

Odoo 20 uses `ir.access` (not `ir.model.access`). Keep
`security/ir.access.csv` in the manifest `data` list:

```csv
id,name,model_id,group_id/id,operation,domain
access___MODULE___example_user,__MODULE__.example user,__MODULE__.example,base.group_user,crud,
```
